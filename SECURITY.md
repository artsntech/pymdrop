# Security Policy

## Supported Versions

Only the latest release of PymDrop is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability (such as an SSRF bypass in the Go proxy or a permission issue in the extension), please report it privately using GitHub's **Private Vulnerability Reporting** feature under the **Security** tab of this repository.

Please do not open public issues for undisclosed security vulnerabilities.
